# Respaldo Privado — Módulo de Visitas Guiadas Granja B-13

Este directorio contiene una copia privada de resguardo del apartado de **Visitas Guiadas** desarrollado para el proyecto La Granja B-13:
- `visitas.html`: Estructura completa, formulario con validaciones en vivo, selector de horarios, integración con Google Maps en Llanquihue 4350 y generación de vouchers.
- `visitas-app.js`: Lógica del cliente, almacenamiento en `localStorage`, generación de folios (`#VIS-B13-XXXX`) y modal de resumen.

**Estado:** 
- Inactivo / Desconectado de la navegación pública de la plataforma web.
- Conservado en el repositorio GitHub como respaldo privado para consulta o reactivación futura sin uso activo.
